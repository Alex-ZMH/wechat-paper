- **语言**：中文。
- **字数范围**：196–219 个中文字符（量化脚本口径，含标题及语料说明）；均值 207.5。
- **年份与发表场所**：无法判断；语料没有可验证的期刊、会议、年份或作者元信息。
- **参考文献格式与引用风格**：无法判断；无参考文献表、文内引文或脚注。
- **投稿约束**：无法判断；不得从短文本长度反推期刊字数、摘要或图表限制。

## L1 学术语言DNA

- **平均句长**：30.03 个中文字符（先逐文计算、再取均值）。短句（≤15 字）占 8.35%，长句（≥50 字）占 8.35%；主体是信息密度适中的中长陈述句。试写时把多数句子控制在约 20–40 字，每 10 句至多保留 1 个 ≥50 字长句。
- **语态与人称**：中文被动语态比例无法由原脚本可靠检测；人工阅读以主动句和无主句为主。第一人称标记按句比均值为 8.35%，全语料仅 1 处“我们”，没有“本文”“本研究”或“笔者”；写作时优先用无主句，必要时才用包容性“我们”。
- **句法节奏**：常用“先纠正直觉判断，再解释机制”的两步推进；用“没有……时，可以……，但不能……”建立证据边界；用“三项/三个问题”式并列把抽象判断转成检查项。
- **连接方式**：转折、条件和递进承担主要逻辑，不依赖堆叠连接词。段首直接给判断，段中解释因果或区分状态，段末落到动作或判准。
- **高频术语**：不列 Top 10。当前环境无法运行分词，且两篇文本过短；把主题词固化为术语会把语料观点误当作风格。
- **套话命中**：原始语料对 35 项黑名单的命中为 0 次。继续规避“具有重要意义”“全面分析”“综上所述”“首次报道”“重大突破”等无证据增益的宣示语，不为满足数量而人为加入。
- **标点偏好**：破折号 0/1000 字符；冒号约 3.96/1000 字符；分号约 2.09/1000 字符。冒号用于引出有限列表，分号仅用于对称条件，避免装饰性破折号。
- **语气**：克制、具体、可执行。少用价值形容词和程度副词；可信度来自限定条件、责任归属和验证动作，而非语势。

## L2 学术结构模板

### 子模板 A：IMRAD（实验性研究）

- **标准结构**：引言（背景 → 进展 → gap → 假设/贡献）→ 方法（样本、设计、流程、统计、可重复性）→ 结果（按发现组织并对应图表）→ 讨论（发现、文献比较、机制、局限、意义）。
- **语料实际用法**：不适用；没有方法、结果、统计或讨论分节。若用于 IMRAD，只迁移“判断 → 机制 → 边界 → 动作”的句段节奏，不迁移任何事实结论；方法和结果必须由新材料独立提供。

### 子模板 B：综述/观点评论

- **标准结构**：引言界定范围与必要性 → 按主题、时间或方法组织主体 → 讨论 gaps、局限与展望。
- **语料实际用法（主要匹配）**：标题或首句提出反直觉判断 → 一段指出常见解释不足并拆解机制 → 一段给出有顺序的行动或审查问题 → 末句以可验证标准，或以可信度、可修订性等实践结果收束。单段只承担一个功能，不作长背景铺陈。

### 子模板 C：学位论文

- **标准结构**：中英文摘要与目录 → 引言/文献综述/理论基础 → 多章方法、结果与讨论 → 综合讨论与结论 → 参考文献、致谢和附录。
- **语料实际用法**：不适用；无章节制、综述规模或后置材料，不能推断学位论文规范。仅可把短文本的判断—解释—行动单元扩展为章内小节。

### 子模板 D：会议论文

- **标准结构**：卖点前置摘要 → 短引言与贡献 → 相关工作 → 方法 → 实验（主结果、消融、案例）→ 短结论与附录。
- **语料实际用法**：不适用；无方法、实验、贡献列表或页数信息。可借鉴简洁标题和快速进入问题，但不得写成无数据的性能宣称。

## L3 选题逻辑

- **写作时机**：当常见解释不足以指导判断，或需要把抽象原则转成可复核步骤时切入。
- **切入角度**：优先从系统状态、证据边界、角色责任和后续动作观察问题，少用个人经历或情绪叙事。
- **gap 识别方式**：不是宣称“研究空白”，而是指出两个可区分层级之间的缺口，例如“能获得信息”与“能据此行动”、“可观察”与“可下结论”。
- **题目与首句**：题目宜用“X，不一定是 Y”或直接的边界判断制造有限张力；首句随后限定范围，不放大为普遍真理。
- **领域偏好**：无法从 2 篇短样本可靠推断。DNA 只保留问题化方式，不授权任何具体学科、主题或立场。

## L4 素材策略

- **引文密度**：0/1000 字；文内引文 0，参考文献 0，主要引用期刊与自引率均无法判断。这是语料缺项，不是今后学术写作应当“零引用”的规则。
- **证据组织**：现有文本主要使用概念区分、条件对照、因果解释和有序检查项，未提供外部数据、案例记录或文献证据。
- **使用护栏（非语料偏好）**：新写作中只能使用任务明确提供且可核验的材料。优先顺序为一手可复核数据 → 明确来源的文献 → 经标注的推断 → 待验证问题；不得把语料中的断言当作证据。
- **数据呈现**：语料没有效应量、置信区间、显著性检验或目标值，均无法归纳。缺数据时只定义指标、观察窗口和验证步骤，不补造数值或效果。
- **引文写法**：需引用时由目标期刊和新资料决定格式；DNA 不提供虚构期刊分布或引用模板。

## L5 认知框架

- **核心表达命题**：① 先缩小并校正常见归因；② 将抽象问题拆成可命名的状态、条件、角色或动作；③ 清楚分隔事实、推断和待验证项；④ 把建议写成有顺序的操作；⑤ 用可推翻条件或验证标准收束。
- **原语料论证链**：限定主张 → 机制性解释 → 条件/反例 → 行动清单 → 判准。优点是紧凑，缺点是没有外部证据和系统的反方比较。
- **正式论文补全框架（非语料中已具备的链条）**：主张（限定适用范围）→ 证据（只列可核验材料）→ 局限（说明缺失与不确定性）→ 反方（给出替代解释）→ 回应（提出可区分的检验）→ 收束（转成结论或下一步）。每一环都必须由新任务材料支持。
- **立场—反方—回应**：先承认直觉解释在何种条件下成立，再指出它解释不了的观察，最后提出区分两种解释所需的证据；不把不同意见写成稻草人。
- **价值判断倾向**：证据保守、行动导向、边界优先。避免“越多越好”“更复杂即更可靠”等未经限定的价值判断。

## L6 视觉风格

- **图表**：平均图数 0，平均表格行数 0；无图题，图题平均字数无法判断。不得据此规定正式论文不使用图表。
- **章节与段落**：Markdown 标题数均值 0.5；每篇 3–4 个文本块。按量化口径，逐文段落平均长度再取均值约 60.04 个中文字符；整体呈短块、高密度布局。
- **排版模式**：一个短标题（如有）+ 说明性起始块 + 1–2 个实质段。正式写作时可保留“每段一功能”和紧凑段落，但须按目标体裁补齐章节、图表和图注。
- **图文协作**：无法判断。若新材料含图表，采用“引导语 → 图/表 → 对观察的限定解读”，不让图表替代证据说明。

## 使用说明

### 适用场景

- 中文论文的引言收束段、讨论段、审稿意见、研究边界说明和短篇分析性评论。
- 需要把概念判断压缩为“机制—条件—动作—验证”链条的文本。

### 不适用

- 直接生成完整实验论文、系统综述、学位论文或会议论文；语料不含相应的方法、引文、统计和图表规范。
- 推断目标期刊、学科惯例、作者身份或具体观点；2 篇短样本不足以支持这些结论。

## 边界

- 本 DNA 只沉淀抽象的学术表达风格。语料仅是风格资料，不授权其中的事实、数字、引文、来源、观点、名称或客户信息。
- 新文本的事实与判断必须由新任务中的可核验材料独立支持；不得把 DNA 当作知识来源或证据来源。
- 不冒充原作者，不抄袭，不绕过查重；相似性应体现在结构、句法节奏和证据边界，而不是复用原句或专有信息。
