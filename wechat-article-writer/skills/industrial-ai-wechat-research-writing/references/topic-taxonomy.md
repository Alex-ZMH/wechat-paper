# 工业调研主题分类与术语边界

## 工业智能体与模型

- 工业智能体：能调用工具、读取上下文并执行受控任务的系统；不要默认它拥有设备写权限或能替代审批。
- 工业/研发/科研大模型：可按数据来源、任务（问答、检索、代码、仿真、规划）和部署边界区分。模型名称、上下文窗口、发布日期等可变信息必须回到官方资料。
- 工业 AI 工具：区分通用模型、工业 Copilot、调度优化器、仿真/材料模型和边缘推理组件，不把“AI”标签当作同一能力。

## 研发与科研工业化

包含材料发现、科学机器学习、仿真代理、实验记录与调度。`MatterGen`、`MatterSim`、`DeePMD-kit`、OR-Tools 等项目的存在或功能由各自官方页面证明；性能、实验复现和生产收益仍需独立证据或明确标为 vendor_claim/案例自述。

### VASP/HPC 硬件销售

- 先按工作负载匹配配置：CPU/GPU 型号与并行方式、内存容量/带宽、NVMe/并行文件系统、网络互联（如 InfiniBand/Ethernet）、VASP 许可证、功耗与散热、节点和集群规模。
- 规格页只能支持原始规格；厂商基准、宣传材料和经销商报价标为 `vendor_claim` 或待核对。没有用户提供的测试条件、输入规模、版本、编译参数和结果，不写速度/性能/ROI 保证。
- 报价、交付、保修、库存是易变商业信息，须带截止日期和来源；VASP 许可证、商标和软件分发边界独立核对，不把硬件出售写成包含未授权软件。

### 计算与实验结合的论文分享

- 分开论文原始结论、作者原创转述、计算假设与 VASP/DFT 输入、计算结果、实验条件与表征、相关性/因果、复现与外推。
- 计算与实验可组成“相互约束的证据链”：例如输入与收敛设置支持计算结论，XRD/XPS/显微等表征支持实验观察；但结果吻合只提高一致性，不自动证明机理、因果或可推广性。
- 不复制摘要、正文、图表或图注；不把相关性改写为因果，不以未提供的输入、实验条件或复现结果填空。

## 制造系统边界

- **MES**：通常聚焦生产执行、工单、过程数据和追溯。
- **MOM**：制造运营管理的更宽语境，可覆盖生产、质量、维护、库存等运营活动；不同厂商边界不完全一致。
- **APS**：高级计划与排程，处理约束、资源和时间安排；不是 MES 的同义词。
- **ERP**：企业资源与财务/采购/订单等业务系统；不能因为 ERP 有生产模块就自动称为 MES/MOM。
- **SCADA**：监控与数据采集，靠近控制/现场层；不要把 SCADA 的实时采集直接等同于执行管理或企业计划。
- ISA-95 可作为企业层、制造运营层与控制层的对照框架，但当前注册表只保留 link-only/manual_required 导航；不要直接摄入受许可限制的正文，需由用户有权访问的标准或允许使用的替代官方说明人工核对。具体产品映射仍需看实施范围。

## 质量与过程工具

- **FMEA**：前置技术风险分析，识别潜在失效、原因、影响和控制措施；AIAG/VDA 汽车语境可按 Planning & Preparation、Structure Analysis、Function Analysis、Failure Analysis、Risk Analysis、Optimization、Results Documentation 七步解释（可中译），但付费手册不做全文摘要。DFMEA 面向设计，PFMEA 面向制造过程；标准解析中 FMEA-MSR 首次写全 `Supplemental FMEA for Monitoring and System Response`（监视与系统响应的补充 FMEA），它不是 PFMEA 的设备维护步骤。版本、客户要求、旧 RPN 与新 AP 的适用关系必须核对，不泛化到所有行业。
- **8D**：问题发生后的结构化纠正与预防流程，重在遏制、根因、验证和防再发；不能把 8D 写成 FMEA 的同义词。
- **APQP/PPAP**：产品质量策划与生产件批准的 Core Tools 语境，版本、行业和客户要求可能不同。
- **SPC/MSA**：过程统计控制与测量系统分析；“用了 SPC”不等于过程一定受控，需看数据和控制规则。

## 必须澄清的歧义

- **FEMA**：制造质量强语境（8D、PFMEA/DFMEA、失效模式、风险分析、控制计划、AIAG/VDA）按高概率拼写转位透明规范为“FMEA（Failure Mode and Effects Analysis，用户原文写作 FEMA）”，首次说明后用 FMEA；弱/无语境追问。若用户明确说它是企业内部流程，保留原词，只问一个短问题核对全称、制度编号或版本、适用组织和原始来源；资料补齐前不生成定义、步骤、评分或方法介绍。灾害、应急管理或美国机构语境保持 `FEMA=Federal Emergency Management Agency`。
- **6A 上下文路由表**：不能固定补全，按下表处理；企业自定义项不能外推。

| 语境线索 | 规范输出 | 证据/写法边界 |
| --- | --- | --- |
| DMAIC、波动、缺陷率、西格玛水平 | `6σ（Six Sigma）` | 透明说明原文可能是输入/OCR 替代；不要改成 API 或铁路语境 |
| 石油天然气、井口、采油树、阀门、PSL | `API Spec 6A` | 记录标准版本与 addendum，不能宣称永久最新 |
| 铁路、机车、制动、防火、高压绝缘、列车供电、走行部、视频 | `机车车载安全防护系统（6A 系统）` | 只按铁路语境解释，不外推质量方法 |
| 企业“6A 服务/管理体系” | `vendor_claim/company_specific` | 只描述企业原始定义，不外推行业标准 |
| 仅“6A”或仅与 8D/FMEA 并列且无线索 | 每个缩写不超过 3 个候选 | 只问一个短问题，要求行业/全称/来源，不猜 |
- “Copilot”“Agent”“平台”“工业大模型”常是营销或产品家族名称，写作时给出厂商原称、能力边界和证据级别。
