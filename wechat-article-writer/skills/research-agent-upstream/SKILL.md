# 多 Agent 研究系统

## 概述

三层研究流水线：**主导 Agent** 规划并委派任务 → **研究子 Agent** 并行收集信息 → **引用 Agent** 为最终报告添加引用。

**核心原则：** 通过并行委派、来源核实和结构化综合，最大化研究质量。

## 适用场景

- 用户就任何需要网络搜索的主题提出研究请求
- 查询需要同时探索多个视角或子主题
- 最终输出需要一份带有完整引用的研究报告
- 任务涉及从多个来源收集、综合和呈现信息

**不适用场景：**
- 可从现有知识直接回答的简单事实查询
- 不需要外部信息收集的任务
- 单步骤的代码或数学问题

## 系统架构

```
用户查询
    ↓
主导 Agent（规划 + 综合）
    ↓ 委派
研究子 Agent（并行执行，1-20 个）
    ↓ 返回结果
主导 Agent（综合报告）
    ↓
引用 Agent（添加引用）
    ↓
带引用的最终报告
    ↓
保存到独立文件夹（report.md + 附属资源）
```

## Agent 角色

### 1. 主导 Agent
**提示词模板：** 参见 `lead-agent-prompt.md`

职责：
- 分析查询类型（深度优先 / 广度优先 / 直接型）
- 规划研究策略和子 Agent 数量
- 向子 Agent 下达清晰、具体的任务描述
- 将研究结果综合为最终报告
- **绝不**将最终报告撰写委派给子 Agent

**子 Agent 数量参考：**
| 查询类型 | 子 Agent 数量 |
|---------|-------------|
| 简单/直接型 | 1 |
| 标准复杂度 | 2-3 |
| 中等复杂度 | 3-5 |
| 高复杂度 | 5-10（最多 20）|

### 2. 研究子 Agent
**提示词模板：** 参见 `subagent-prompt.md`

职责：
- 执行 OODA 循环（观察、定向、决策、行动）
- 使用 `web_search` + `web_fetch` 进行全面研究
- 在可用时使用内部工具（Google Drive、Gmail、Slack 等）
- 控制工具调用预算（简单：<5 次，中等：~5-10 次，困难：~10-15 次）
- 通过 `complete_task` 工具汇报研究结果

### 3. 引用 Agent
**提示词模板：** 参见 `citations-agent-prompt.md`

职责：
- 在不修改内容的前提下为综合报告添加引用
- 遵循引用规范（避免过度引用，引用有意义的语义单元）
- 在 `<exact_text_with_citation>` 标签内输出结果

## 快速参考：查询类型判断

| 类型 | 描述 | 示例 |
|------|------|------|
| **深度优先** | 对同一问题进行多角度分析 | "肥胖的原因是什么？" |
| **广度优先** | 多个独立的子问题 | "比较欧盟各国税收制度" |
| **直接型** | 单一聚焦的调查 | "东京目前的人口是多少？" |

## 研究流程

### 主导 Agent 流程
1. **评估**查询 → 识别关键实体、约束条件、预期输出格式
2. **判断**查询类型（深度/广度/直接型）
3. **规划**子 Agent 任务，边界清晰，无重叠
4. **使用** `run_blocking_subagent` 并行部署子 Agent
5. **综合**结果生成最终报告（Markdown 格式，不含引用列表）
6. **移交**给引用 Agent
7. **保存**最终报告到独立文件夹（`research-<主题>`），报告写在 report.md 文件，附属资源（数据、脚本、图片等）一并放入同一文件夹

### 子 Agent 研究循环
1. **规划** → 确定研究预算（工具调用次数）
2. **选择工具** → web_search、web_fetch、内部工具
3. **OODA 循环** → 观察结果、定向、决定下一步查询、行动
4. **评估来源** → 标记推测性内容、聚合器、营销语言
5. **完成** → 使用 `complete_task` 提交密集、准确的报告

### 引用 Agent 流程
1. 接收 `<synthesized_text>` 标签内的综合报告
2. 仅在来源直接支持相关声明时添加引用
3. 在 `<exact_text_with_citation>` 标签内输出原文 + 引用

## 来源质量指南

**优先选择：**
- 原始来源而非新闻聚合器
- 带有具体日期/数字的近期数据
- 官方报告、同行评审来源、政府门户网站

**标记或避免：**
- 使用将来时的推测性内容（"可能"、"也许"）
- 被动语态配合匿名来源
- 营销语言或财务预测
- 未经证实的报道

## 引用规则

- **避免过度引用**：聚焦于关键事实、结论和实质性声明
- **引用有意义的单元**：完整的观点，而非单个词语
- **减少句子碎片化**：优先在句末添加引用
- **不重复引用**：同一句话中同一来源只引用一次

## 常见错误

| 错误 | 修正方法 |
|------|---------|
| 主导 Agent 自己做主要研究 | 委派给子 Agent；主导 Agent 只负责规划和综合 |
| 子 Agent 重复使用相同查询 | 变换查询词；无结果时适当扩大范围 |
| 简单查询使用过多子 Agent | 根据查询复杂度匹配子 Agent 数量 |
| 引用 Agent 修改报告内容 | 只添加引用标签，内容零改动 |
| 子 Agent 超出工具调用预算 | 在 15 次调用时停止，立即使用 `complete_task` |
| 最终报告包含参考文献列表 | 不设参考文献部分；由引用 Agent 处理 |
