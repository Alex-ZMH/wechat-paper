# 真实 writer 人工审查

> 历史说明：本文记录的是早期真实 writer 运行和人工阅读材料，不是当前 `source-verification` 或 `content-review` 的通过证明，也不是用户人工验收。旧的 2026-09-22“博士工作去向调查”成功样本经新的 `source-verification` 逐页读取公开 HTTP/HTML/PDF 并逐字匹配摘录时，发现一处摘录未标注删字而被拒绝；因此该记录只能称为联网返回结构化结果，不能称为独立来源核验通过。`content-review` 是 AI 独立核对 claim、正文数字范围与来源并审查逻辑、重复、文风和可读性的复核，结果绑定当前内容指纹并持久化，修改后失效，仍不替代人工验收。保存和审阅稿下载不因复核失败而阻塞；正式定稿仍需内容复核和既有人类确认门禁。新真实测试尚待主代理完成，待补记录引用见 `evaluation/IMPROVEMENTS-20260922.md`。

本轮使用本机已认证的 `codex-cli`（`gpt-5.6-sol`）和结构化 JSON Schema，完成 11 个不同类型的真实选题。每个选题先由人工整理并核验来源 URL 的 EvidencePacket，再经过 confirmed ArgumentMap、真实 writer、机械 ReviewReport 和 WechatPackage。来源在合同中显式标记为 `human_curated`；旧 Bridge 的实时研究结果没有混入本轮证据。

五项检查是人工逐篇阅读，不是 `ReviewReport` 自动分数：逻辑推进、证据准确性、重复表达、文风一致性、可读性。任一项不通过，都不能把 writer 称为高质量。

## 交付判断

- 11/11 真实调用均已用当前来源定义重新生成；其中 10 篇使用 `gpt-5.6-sol`，钙钛矿在 sol 超时后使用同一真实 provider 的 `gpt-5.6-luna` 完成，模型差异已在 JSON 顶层标为 `mixed`。
- 11/11 的每个正文段落都有已知 `claimIds`，并能沿 `EvidencePacket.claims → evidenceIds → sources` 追溯；这是结构覆盖率 100%，且已逐段完成语义来源复核。
- 11/11 `ReviewReport` 均为 `approved`，`WechatPackage` 均为 `ready`；来源审计发现的问题已修正并在新运行中复核。
- writer 失败、模型不存在、非 JSON、未绑定 claim、未覆盖 claim 的测试均确认会报错，不会套用样例文章。

## 最终签字状态

11 篇均通过五项人工检查；MOF 的“固态/准固态”边界、CATL 企业披露限定、模型成本假设和推断语气均已复核。实时研究超时 E2E 返回 `research_timeout` 并释放 Bridge `busy` 状态；最终测试无回归。**主代理签字：当前结构化 writer 垂直切片达到本轮验收标准；仍不开发图片、发布或多平台功能。**

补充：本轮曾调用旧 Bridge 的 `/v1/research`，在 240 秒内停留在 `research_retrieval/research_audit`，因此没有把一次未完成的研究结果伪装成证据。实时研究 adapter 的超时处理列为最后一个独立任务。
